# Dona Sebastiana · site

Página única em HTML, CSS e JavaScript puros. Não precisa compilar: abre com duplo clique no `index.html` e publica em qualquer hospedagem estática. Para o GitHub, é só subir o conteúdo desta pasta.

## Arquivos
```
index.html      página e todos os textos
styles.css      visual
main.js         links de checkout, links das redes e animações
fonts/          Alegreya (texto) e Caveat (letra de mão), licença OFL
assets/img/     fotos e capas em WebP
PENDENCIAS.md   o que falta confirmar antes de publicar
```

## O que trocar
- **Links de compra e redes:** topo do `main.js` (`CHECKOUT` e `REDES`).
- **Textos e preços:** direto no `index.html`.
- **Fotos:** substituir o arquivo em `assets/img/` mantendo o mesmo nome.
